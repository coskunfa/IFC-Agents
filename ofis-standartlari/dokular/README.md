# Doku ve Aksesuar Kütüphanesi (kat planı boyama için)
Ofisin boyamalarda kullandığı üstten görünüş dokuları ve objeler. [DOLDURULACAK: kullanıcı PSD/doku arşivini arıyor]

Ofisin dokuları bulunamazsa PAFTA lisansı uygun (ücretsiz ticari kullanım) kaynaklardan aday dokuları önerir; kullanıcı seçer, seçilenler buraya kaydedilir. **Onaylanmamış doku kullanılmaz.**
- `zemin/`: ahşap parke, mermer, seramik, doğal taş, çakıl, balıksırtı taş, çim
- `bitki/`: üstten ağaç/çalı kümeleri (şeffaf PNG)
- `mobilya/`: üstten koltuk, yatak, masa, vitrifiye (şeffaf PNG)
- `arac/`: üstten araç görselleri
