# Doku ve Aksesuar Kütüphanesi (kat planı boyama için)
Ofisin boyamalarda kullandığı üstten görünüş dokuları ve objeler. [DOLDURULACAK]
- `zemin/`: ahşap parke, mermer, seramik, doğal taş, çakıl, balıksırtı taş, çim
- `bitki/`: üstten ağaç/çalı kümeleri (şeffaf PNG)
- `mobilya/`: üstten koltuk, yatak, masa, vitrifiye (şeffaf PNG)
- `arac/`: üstten araç görselleri
