# Tefriş ve İşlev Kuralları

PAFTA boyamadan önce, DENETÇİ de kontrol sırasında bu tabloyu kullanır.
Amaç: her mahalde, büyüklüğüne göre olması gereken işlevlerin ve mobilyaların bulunması ve **mobilyaların gerçek ölçüde** olması.
[Kullanıcı zamanla günceller]

## Mahal bazında olması gerekenler
| Mahal | Alan | Olması gerekenler |
|---|---|---|
| Salon | < 25 m² | Oturma grubu + TV ünitesi |
| Salon | 25–40 m² | Oturma grubu + TV ünitesi + yemek masası (4–6 kişilik) |
| Salon | > 40 m² | Oturma grubu + TV ünitesi + yemek masası (6–8 kişilik); varsa şömine/okuma köşesi |
| Mutfak | açık | Tezgâh (L/U/düz) + eviye + ocak + buzdolabı; ≥ 12 m² ise ada veya kahvaltı masası |
| Mutfak | kapalı | Tezgâh + eviye + ocak + buzdolabı + (yer varsa) kahvaltı masası |
| Ebeveyn yatak odası | | Çift kişilik yatak (160–180×200) + 2 komodin + gardırop (veya giyinme odası) |
| Yatak odası | ≥ 10 m² | Çift ya da tek kişilik yatak + komodin + gardırop + (yer varsa) çalışma masası |
| Yatak odası | < 10 m² | Tek kişilik yatak (90–100×200) + gardırop |
| Banyo | | Klozet + lavabo + duş (≥ 90×90) veya küvet |
| Ebeveyn banyosu | | Klozet + çift ya da tek lavabo + duş/küvet |
| WC | | Klozet + lavabo |
| Çamaşır odası | | Çamaşır makinesi + kurutma + tezgâh/dolap |
| Giriş holü | | Vestiyer/ayakkabılık |
| Teras / bahçe | | Oturma grubu ve/veya dış yemek masası; havuz varsa şezlonglar |
| Otopark | | Araç (250×500) + manevra alanı |

## Mobilya ölçüleri (kontrol aralıkları, cm)
| Mobilya | Ölçü |
|---|---|
| Çift kişilik yatak | 160×200 – 180×200 |
| Tek kişilik yatak | 90×200 – 100×200 |
| 3'lü koltuk | 210–240 × 85–100 |
| Tekli koltuk | 75–95 × 75–95 |
| Yemek masası 6 kişilik | 160–200 × 90–100 |
| Yemek masası 8 kişilik | 220–260 × 95–110 |
| Gardırop derinliği | 60 |
| Mutfak tezgâhı derinliği | 60–65 |
| Klozet | 36–40 × 53–60 (ofis bloğu IFC_KLOZET 36×53.4) |
| Lavabo | 50–80 × 45–55 |
| Araç | 250 × 500 |

## Geçiş açıklıkları
- Mobilya arası ana geçiş ≥ 80 cm, yatak kenarı ≥ 60 cm, mutfak tezgâh önü ≥ 100 cm (karşılıklı tezgâhta ≥ 120 cm).
- Kapı açılışı mobilyaya çarpmaz.

## Eksik ya da yanlış olduğunda
1. Mahal yeterliyse: PAFTA tefrişi tamamlar ve raporlar.
2. Mahal yetersizse ya da tasarım kararı gerekiyorsa: ŞEF kullanıcıya sorar **veya** çizimi ÇİZGİ'ye revizyona gönderir.
