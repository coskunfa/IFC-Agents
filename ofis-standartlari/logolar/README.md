# Logolar

| Dosya | Kullanım |
|---|---|
| `IFC_Architects_logo_koyu.png` | **Varsayılan.** Beyaz zeminli paftalar (koyu gri #3C3C3C, şeffaf zemin, 1504 px) |
| `IFC_Architects_logo_siyah.png` | Siyah-beyaz çıktılar |
| `IFC_Architects_logo_beyaz.png` | Koyu zemin / render / fotoğraf üstü |
| `IFC_Architects_logo.jpg` | Şeffaflık desteklemeyen yerler |
| `IFC_LOGO.dxf` | AutoCAD pafta başlıkları için kaynak. Tek MTEXT: `IFC` = **Swiss 721 Black Extended BT**, `A r c h i t e c t s` = **Bahnschrift SemiBold** (harf aralıklı). |

- PNG'ler sunum PDF'inden 600 dpi'da üretildi. Logo yazı tipleriyle yeniden çizilirse yukarıdaki fontlar kullanılmalı.
- Logo yalnızca görsel olarak yerleştirilir; oranı bozulmaz, rengi değiştirilmez (yalnızca koyu/siyah/beyaz sürümler).
- İşveren logoları buraya **değil**, ilgili projenin `00-girdi/logo/` klasörüne konur.
